Storage and preference choices in Artanrecords Studio.

Effective date: 2026-10-19Last updated: 2026-10-20

Essential storageOptional preferencesAnalyticsChange your choices

Essential storage

Consent choices and account security use necessary browser storage. Essential storage is always active. Studio uses session storage to keep your sign-in within this browser tab; account access does not require consent to optional preference memory.

Optional preferences

With preference memory allowed, this browser remembers appearance, contrast, palette and workspace sidebar choices across visits. Declining optional storage keeps changes in session storage until the tab session ends. These choices do not currently synchronize to an artist account.

Analytics

Analytics are not connected. Choosing an analytics preference does not activate tracking or create listening or royalty reports. Any future analytics service must be disclosed here before activation.

Change your choices

Open Cookies & preferences from the footer or Privacy settings to save individual choices, allow optional categories or decline them. Withdrawing preference memory removes persistent Studio appearance and navigation settings from this browser; essential consent and security records remain separate.
