# Artan Records Documentation

Target domain:

`https://docs.artanrecords.com`

## Purpose

This directory is the source area for the future public Artan Records documentation site.

It should eventually contain approved public guidance for artists and collaborators, including:

- getting started
- artist submissions
- release workflow
- metadata standards
- artwork requirements
- audio requirements
- rights overview
- royalty and payment guidance once approved
- Studio help
- public policies
- FAQs

## Boundary

This directory is for PUBLIC documentation only.

Do not automatically publish:

- internal business strategy
- private financial models
- security architecture
- unpublished legal strategy
- internal fraud controls
- deployment secrets
- private artist records
- private contracts
- internal operational notes

`Business.md` is private/local and must not be copied here automatically.

## Design

The documentation site should share the Artan Records brand foundation from `/shared` while remaining optimized for:

- reading
- navigation
- search
- semantic HTML
- accessibility
- responsive layouts
- durable URLs
- deep linking
- SEO

## Deployment

This directory will eventually deploy independently to:

`docs.artanrecords.com`

Do not change live DNS or deployment configuration without explicit approval.
